# 驚喜學院制度

> 2026-08-04建立。跟[收費制度.md](收費制度.md)的分工：那份管「錢」（定價/付款/退款），這份管「內容怎麼分類、怎麼被存取、怎麼被體驗」，不重複。
>
> **「驚喜學院」是CC/文件內部整理用的概念統稱，不是客人在網站上會看到的正式名稱。** 客人實際看到的是「小教室」「心理學館」等更親切具體的命名，內部分類詞跟客人看到的行銷命名可以不一樣，不強制統一成同一個詞——「學院」的正式/教育感跟魯魯品牌的可愛療癒調性有點衝突，維持現況命名。

## 一、整體階層架構

```
驚喜學院（內部統稱，最上層）
  └─ 書院（大類別）：理財書院／心理學書院／AI書院／腦中宇宙書院／好康書院...
       └─ 系列（書院內）：例如心理學書院6學系、AI書院9系列、理財書院2系列
            └─ 產品（系列內）：每一本書／每一套課程
                 └─ 產品內容可衍生：推廣素材／繪本依據...（非必要，可選）
```

### 兩個例外，明講避免以後誤用

**好康書院不是獨立內容類別，是跨書院的試讀聚合視圖。** 它把其他真正書院（理財書院/心理學書院/AI書院/自律神經）的免費堂/試讀內容抓出來集中展示，本身不擁有內容。**以後有新內容，不要誤塞進「好康書院自己的系列」，要掛在正確的來源書院底下**，好康書院只是多一個展示入口。

**繪本/推廣可以完全獨立於這個階層存在，這是刻意設計，不是遺漏。** 像暗夜觀察日記、情緒勒索這類繪本系列，主題不需要對應到任何一個書院/系列，可以自己獨立存在，只選擇性地跟某個書院做CTA導流（例如繪本結尾導去心理學書院）。實際live網站已經這樣實作：「暗夜觀察日記」是首頁獨立卡片，不在「小教室」或「心理學館」底下。**以後有新的繪本/推廣構想，不需要被要求「這個要掛在哪個書院系列底下」才能做**，避免把不需要規則化的東西過度規則化。

**心理學館因為是28本書的旗艦內容，首頁層級獨立曝光，不強制收進「小教室」底下**——這是刻意的商業判斷（旗艦內容值得首頁單獨曝光，不用讓訪客多點一層），不是架構混亂，不需要為了文件乾淨而要求網站改版對齊。

## 二、理財書院內部結構（2026-08-04定案，含股市書院改名）

**「股市書院」已於2026-08-04全面改名「理財書院」**（ST/SS/AIOS三repo共20處已改名，見ST repo memory `project_pending_commits_20260804`）。

```
理財書院
  ├─ 台股系列（入門/進階/高階，循序漸進curriculum，教「怎麼判斷」的方法論）
  └─ 理財調查局系列（案件式財經分析格式，目前有ETF案，未來可擴充個股案/其他金融商品案）
```

**兩者的差異不是主題（不是一個管台股一個管ETF），是教學格式**：
- 台股系列＝打底的系統性課程，教你工具（K線/均線/籌碼分析等）
- 理財調查局系列＝應用式的案件拆解，教你怎麼用工具破一個真實案子

「調查局」是**案件式財經分析的內容格式/品牌**，不是專屬ETF的品牌——現在只是碰巧第一批內容做的是ETF，格式本身沒有限定主題，之後可以擴充個股案（例如「案006：這檔股票該不該買」）。兩系列甚至互補：學完台股系列工具的人，可以去理財調查局的案件裡實戰演練。

**不要把理財調查局提升成台股的上層、或把ETF拆出來當獨立系列**——會打散原本設計好的組合（ETF電子書＋案件課程本來就是理財調查局系列自己的一套內容）。

## 四、書院UX規則

- 每堂完課→完課畫面→繼續/返回；有知識卡則顯示卡片；整冊最後一堂才發證書
- 免費堂＝完整真實課程內容，不是另做的縮減試讀版（詳見[課程製作SOP.md](課程製作SOP.md)）
