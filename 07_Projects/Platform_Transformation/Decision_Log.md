## 2026-07-03｜平台三層架構：Marketing / Product / Membership
Decision：整個平台拆成三層，只有 Product 層適用下面的三分類（bundle/course_only/ebook_only）：
- **Marketing**：免費測驗、文章、SEO、活動——不是 Product，不進三分類 schema，純粹是 SS 的導流入口
- **Product**：ebook、course、bundle——適用三分類
- **Membership**：訂閱、書院、SD——另一套邏輯，不套用三分類
Why：避免把「免費導流頁」跟「付費商品」混在同一個 schema 裡，兩者的技術需求（是否要解鎖權限、是否要進訂單系統）完全不同。
Owner：妹 / ChatGPT / CC 三方一致同意

## 2026-07-03｜Series ContentType 三分類定案

## 2026-07-03｜商品折扣機制定案：contentType 數量折扣，取代心理學專屬系列定價
Decision：
- 放棄 GPT 建議的「試讀→入門→進階→高階→完整系列」分層升級制，不做老買家比例折抵、不做自動解鎖下一級這類複雜機制
- 每本書／每個課程維持獨立單本定價
- 折扣改用「購物車內同一個 contentType 累計件數」計算，**不分主題／不分書院**：2 件 9 折、4 件 85 折、6 件以上 8 折
- 跨 contentType 不能湊數量（例如 1 本 ebook_only + 1 個 course_only 不算 2 件）
- 心理學 28 本原本的專屬系列定價（單本 249／4 本 699／6 本 999／全系列 2499）正式廢除，改套用這個通用規則
- 舉例：買 1 本 AI 書院（bundle）+ 2 本心理學（bundle）＝ 3 件 bundle 一起累計算折扣，不管主題是否相關
Why：妹認為 GPT 的分層升級制太繁瑣、要處理的邏輯太複雜；改用單本定價 + 同 contentType 數量折扣更單純，還能跨書院累計，反而更鼓勵多買不同主題的內容。
Owner：妹

Decision：ST repo（`my-bookstore-next-V2`）商業規則規格書 v1.0 的 Phase 4（Order Persistence & Payment）正式完成並封存，不再回頭修改。範圍：`PurchaseOrder`/`PaymentTransaction` model、`OrderRepository`、`PaymentAdapter` 抽象介面（`manual_transfer` + `mock` 兩個實作）、`PaymentService`（Transaction Flow + Idempotency）、`GrantService`（實際寫入 `UserPurchase`）、`POST /api/checkout`、`POST /api/payment/callback`。完成後先做一輪多角度 code review 才驗收，抓到 Critical 安全漏洞（callback 零認證 + client 可自選測試用 `mock` provider，兩者疊加可免費觸發真實商品授權），已在 Phase 4.1 Hardening 修復（admin session 認證、paymentMethod 白名單、idempotency retry 修復、transactionId-based CAS）。64 個單元測試全過，經第二輪 adversarial verification 確認修復無誤、無新增 regression。下一步進入 Phase 5（Checkout UI / 我的訂單 / 我的電子書 / 付款成功頁 / 付款失敗頁等使用者可見功能），Phase 1～4 程式碼不再回頭重新設計。

## 2026-08-08｜《暗夜觀察日記》v2圖文聲製作原則：無字母母圖資產化＋文字位置跟隨構圖＋短語音導演設計
Decision：
- **每頁必須永久保存「電影級無文字母圖」**，這是核心視覺資產，不得覆蓋。正式文案定稿後，再從同一張無字母圖製作正式燒字閱讀版；正式文字不交給生圖模型直接生成（避免錯字/字形/排版失控），應在圖片完成後精確排版再輸出。每頁原則上保留：①無字母圖 ②中文正式燒字版 ③英文正式燒字版。系列名／單冊名主要屬封面／書籍資訊，不需要固定燒在每張故事圖片上。

- **文字位置跟著電影構圖，不固定座標**：不要求所有頁面文字永遠在左下/右下或固定區域，依人物位置/視線/光影/負空間/情緒決定。固定的是整冊字體系統、字級層級、行距、安全邊界及品質感，不是固定文字座標。手機閱讀優先，不得為塞入文字而縮小到難以閱讀；文字與畫面衝突時優先精簡文案或調整分鏡。
- **圖片×文字×短語音必須同步設計**：不得是「圖片完成→塞文字→最後交給TTS朗讀」。每頁在故事/分鏡階段就要同步考慮畫面讓讀者看見什麼、畫面文字讓讀者留下什麼、短語音讓讀者感受到/繼續往前什麼，三者共同承擔敘事不機械重複。允許「強畫面+一句字+短語音」「畫面+無字+短語音」「畫面+文字+無語音」甚至純畫面+沉默等組合。
- **短語音是導演設計，不是附加TTS**：分鏡同步定義語音內容及情緒指示（語氣/速度/強弱/停頓/留白），補足畫面沒說出的心理活動/節奏/情緒，不是逐字複誦燒在圖片上的文字。**免費精簡版也維持正式產品級語音品質，不能因為免費使用明顯廉價/機械式TTS**。實際語氣/停頓能否做到由語音工具測試確認，內容設計階段須先給導演意圖。

Why：避免重演「圖完成後才想文字怎麼塞、語音只是把字唸一遍」的舊流程問題；無字母母圖保留是為了不讓「這次為了塞中文字做的排版」污染未來想做英文版/桌布/社群素材的可能性。
Owner：妹（原則拍板）／GPT（分鏡與內容設計，含測試圖/短語音brief）／CC（reader技術結構review）

## 2026-08-27｜SS/ST/外部平台完整分工模型（同日修訂強化版，取代當天稍早模糊表述）

**⚠️ 本條正式取代 2026-08-25「北極星原則」條目裡「社群→SS→ST」單一漏斗的框架（該條目其餘內容如節慶年曆規劃、免費版只給問句原則不受影響、繼續有效），也取代本檔案同日稍早版本的「SS/ST導流原則重新拍板」條目——稍早版本用「ST→SS允許、SS→ST商品導購不是SS的任務」的措辭，妹認為仍可能被誤讀成「SS可以做軟性/包裝過的導購」，這版用更精確的模型取代，不是疊加修正。**

Decision：SS、ST、外部平台（社群／Pubu／廣告／未來的Lulu個人影響力）三者是**三個不同角色**，不是「SS是ST的前導漏斗」：

1. **SS驚喜角落＝純免費流量站，絕不承擔商品推銷任務。** 免費玩／免費看／免費測／免費工具／免費課程知識／冷知識／AI快訊／Lulu撿到等，使用者來就是單純享受免費內容，體驗到此完整結束。SS明確**不做**：
   - 「看一半→去ST買完整版」的切半體驗
   - 「免費試讀→去ST解鎖」的解鎖CTA
   - 推薦相關商品
   - 顯示商品價格／折扣
   - 任何購買CTA（含「立即購買」「前往小舖解鎖」等直接商業動詞）
   - **把「購買」包裝成比較柔和的「去小舖看看」來偷偷保留導購意圖**——這種偽裝軟性導購同樣禁止，不是把動詞換掉就合規
   - Footer／Navbar等**品牌識別／站點導航例外**：讓使用者知道「有的沒的小舖」與SS的品牌關係、或提供一般性站間連結，不算推銷，不需要為了這條規則刻意切斷SS/ST的品牌關係
2. **ST有的沒的小舖＝作品／課程／商品的家。** 電子書、有聲書、繪本、影片商品、完整課程等放ST；ST裡可以同時有完全免費作品/課程、付費作品/課程、商品試閱、完整商品。**判斷SS/ST的標準不是「免費或付費」**——免費體驗/流量內容→SS，作品/課程/商品（其中也可以有免費品）→ST。
3. **真正負責導流與推廣的是外部平台，不是SS。** 社群平台／Pubu等外部作品銷售平台／未來的廣告，依內容與受眾把人分流到SS（想免費玩/看/探索）或ST（想看作品/課程/商品），**可以同一則內容雙導SS+ST，也可以只導其中一站，不要求每次一定雙導**。若未來Lulu在IG/Threads/FB/YouTube等平台養出自己的受眾，Lulu本身就是這套外部曝光中心的一份子，同樣雙導SS+ST，不需要先進SS再被SS推去ST。
4. **ST的作品可以挑選少數做成SS的完整免費版**，作為免費試玩/試用/試讀/試聽——重點是「挑選少數」，不是每個ST商品都要另外做SS版本，也不是把商品故意切一半放SS。放上SS的免費內容本身必須可以完整享受，**在SS裡不接續任何推銷ST的動作**；真正讓使用者知道「還有更多作品/商品」的是外部平台的反覆曝光，不是SS當場推銷。
5. 預期的使用者路徑因此是雙向、非線性的：「社群/廣告→SS免費體驗→離站」、「社群/Pubu→ST看更多作品/商品」都成立，使用者可能先進SS也可能先進ST，靠SS/ST**同品牌識別**讓人多次曝光後自然認出「這是同一家」，不是靠SS當場把人推過去。
