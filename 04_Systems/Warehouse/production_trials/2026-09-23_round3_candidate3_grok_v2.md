# Round3候選③v2：魯魯開關故障（Grok重寫版，取代v1）

**為什麼有v2**：Grok用CC轉告的兩個新標準（內容不能太單薄+媒介不該預設是動畫）複查v1，**自己判定「原版禁不起這兩個標準，要重寫，不是微調」**。完整教訓見`LEARNINGS.md`「Round3第一個/第二個失誤」章節。

## Grok的自我診斷

**原版為什麼單薄**：原8秒只示範了一個開關（舔→出聲被掐→舔→另一句被掐→舔），陌生人讀到的是「貓影片配了兩句沒講完的話」，不是「存在狀態失控」。三個原因：
1. **只有開關，沒有改寫規則**——每一拍都在重複同一件事（聲道時有時無），觀眾對世界的認知最多改一次（原來這貓會叫），後面都是同一規則的回音
2. **戲幾乎全在聲音上**——靜態demo看不懂是必然，就算真的播，靜音也看不懂，視覺可讀性不夠
3. **故障被人設吃掉**——同一姿勢疊兩次人聲，很像配音小品，要讓人感到「接觸不良」，必須讓同一具身體出現兩個不同步的時鐘，而且「對你說話」這件事本身也要會當機

## Grok的媒介分析（回答CC的第2個問題）

| 形式 | 適不適合 |
|---|---|
| 全動畫/全生成 | 不適合。一開始就不是真貓，故障沒有對照組 |
| 單張圖 | 不適合。開關不存在 |
| 普通漫畫氣泡 | 弱。漫畫裡動物本來就會講話，沒有「不該活」的違和感 |
| **真貓影片+局部驅動（嘴/眼）+聲音直切** | **切片測試的正確媒介，策的直覺對** |
| 站內日常貼文被寄生（同一則真貓內容偶爾活、偶爾死） | **這機制完整時該住的地方**——「下一秒不可預測」在feed裡才是真的；寫死在10秒裡，看第二次就會變成節拍器 |
| 互動（點了有時說話、有時只是貓） | 能放大，但會多出一套操作規則，round3先不要換驗證目標 |

**Grok的第一作者判斷**：不要做成動畫短片。Round3只拍「真片被局部附身」的10秒切片，用來驗證怪感在不在。完整玩法以後是寄生在SS真貓內容上，不是開一條動畫產線。

## Storyboard v2（10秒，真片+局部驅動，4次改寫規則）

仍只用：真貓魯魯、活起來的魯魯、舔爪子。**粗的是畫質、嘴型、一致性；不粗的是四次改寫規則，而且靜音也要看得出狀態在跳。**

**0.0-1.8秒｜規則A：這是真貓日常**：真片，低頭舔左前爪。無聲、無字幕、不看鏡頭。觀眾以為自己在滑普通貓影片。

**1.8-3.2秒｜規則B：原來是會講話的貓**：同一段真片，只有嘴被局部驅動，對上半句：「我跟你們說——」嘴型可以很醜。觀眾改判：哦，講話貓。

**3.2-4.2秒｜規則C：不是角色，是被掐斷**：「說」字硬切。嘴停在微張，停約0.3秒（卡住，不是換氣），然後啪地回到閉嘴舔爪。身體節奏完全不承認剛才開過口。觀眾改判：不是人設，是故障。

**4.2-5.5秒｜讓規則C坐住**：只舔，夠長。讓人以為這則已經修好轉回日常。

**5.5-7.8秒｜規則D：一具身體兩座時鐘**：嘴再次驅動，接的是另一條斷線，不是上一句的續集：「昨天那位說我——」同時左前爪繼續用真貓的節奏舔，和嘴不同步。不要把全身演成在說話。觀眾改判：不是配音軌道壞了，是兩個存在搶同一具身體。

**7.8-10.0秒｜規則E：連「對你活著」也會當機**：頭開始抬、眼睛對上鏡頭，像要主持。話沒接完。抬到一半，聲斷、嘴停、眼睛空掉，頭掉回去，接著舔。結束在真貓，不看鏡頭、不收梗。觀眾改判：連「它在跟我說話」都不可信。

**四次改寫總結**：日常 → 會講話 → 講話可被掐且本體不認 → 兩座時鐘 → 面向你也會斷電。

## Grok對「靜態可讀版」的替代建議（若下一輪還需要）

不要再交一張肖像。交五格「被中斷的真片截圖」，時間碼寫在畫面上，當監控/日常片壞掉的證據，不是漫畫對白：
```
0:01 舔爪，無氣泡
0:02 同一姿勢，半句被切掉的字
0:03 嘴仍微張，字消失，爪子繼續
0:06 嘴在說另一半句，爪子節奏明顯不配
0:09 抬頭對鏡停住，下一格已低頭在舔
```
這是給靜態複查用的，不是主媒介。主媒介仍是真片被局部附身。
