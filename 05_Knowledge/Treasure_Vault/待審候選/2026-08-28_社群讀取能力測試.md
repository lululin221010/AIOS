## 一、讀取能力測試報告

### 1. 瀏覽器連線方式說明

- 我使用的是 Claude Code 內建的「Browser pane」工具——一個獨立的沙盒瀏覽器，跟妳日常用的 Edge/Chrome是**完全分開的環境，不共用妳的登入cookie**。
- 這跟 GPT 的雲端瀏覽器是不同系統，我沒有也不會嘗試接管 GPT 那個 session，也沒有搬移任何 cookie／token。
- **視覺同步未完成確認**：本次測試 `screenshot`（視覺畫面）功能回報「Browser pane 未顯示」，代表這個分頁目前沒有渲染到妳的畫面上，我無法跟妳「同步看到同一頁」來完成妳要求的第一步確認。但文字讀取（`get_page_text`/`read_page`，讀取頁面文字與結構）功能正常運作，本報告的資料都是靠這個管道讀到的，不是靠畫面判讀。
- 如果妳的 Claude Code 介面本身有 Browser pane 面板，麻煩看一下現在是否顯示得出畫面；如果沒有，代表「畫面同步」這條路在目前環境下可能行不通，但不影響文字資料讀取這條路。

### 2. 各平台測試結果

**Threads**
- 不登入狀態下，首頁（threads.com）可讀到約 **4 篇固定貼文**——這不是可捲動的即時動態，是伺服器端渲染的固定內容，往下捲動不會載入新貼文。
- 可讀到：作者帳號、貼文全文、相對發文時間、貼文永久連結（URL）。
- 首頁列表每篇貼文顯示4個數字，**推測**依序為讚／留言／轉發／分享，但進入貼文詳細頁後，只有「讚」這個按鈕有明確標籤(aria-label)對應數字，其餘3個按鈕沒有帶數字標籤——**這點無法100%確認對應關係，標記為存疑，未在候選表格中直接當作可信數據使用**。
- 指定貼文（進入詳細頁）：可額外讀到瀏覽次數（例如「2.2萬次瀏覽」）、精確發文時間。
- 私人儲存內容（收藏）：找不到不需登入的存取路徑，合理推測需要登入，**未嘗試登入，未驗證**。

**X（Twitter）**
- `/explore` 或首頁：**立即跳轉登入頁**，完全無法在不登入狀態下存取，已停止不再嘗試（符合安全邊界：遇到登入限制就停下）。
- 但**指定的公開帳號個人頁面**（測試用 x.com/nasa）不登入可以正常讀取，而且資料完整度最高：貼文全文、精確時間戳記、貼文永久連結、回覆數、轉發數、按讚數、瀏覽數，**全部都有清楚的 aria-label 標籤**（reply／repost／like／view count 分開標示），可信度優於 Threads。
- Bookmarks／指定清單：兩者都是登入後才看得到的個人化內容，不登入完全無法測試，**沒有嘗試登入**。

**Instagram**
- 個人頁面（如 instagram.com/nasa）：不登入可看到粉絲數、簡介、貼文縮圖清單與連結，但縮圖本身**不顯示**按讚／留言數字。
- **指定貼文詳細頁**（如 instagram.com/nasa/p/...）：不登入可以完整讀到貼文全文、精確日期、留言列表（含留言者帳號、留言時間、留言內容）、讚數、留言總數，資料完整度也很高——畫面上方會跳出要求登入/註冊的彈窗，但**不影響底層資料讀取**。
- 收藏（Saved）／Reels 個人化列表：同樣需要登入，不登入找不到入口，**未嘗試登入**。

### 3. 三平台共通結論（回應「不登入也能看到設定條件發文才對吧」）

**是的，確認成立**：三個平台的「指定貼文／指定公開帳號」都能在不登入狀態下讀到主要資料（作者、時間、連結、部分或完整互動數字）。**登入牆卡住的是「個人化/私人內容」這一類**——X的Bookmarks和指定清單、Threads和IG的收藏(Saved)、以及依賴帳號登入狀態產生的個人化推薦首頁（如妹自己畫面上那個「為你推薦」feed）。這跟「換哪個AI操作」無關，是這三個平台本身的存取權限設計。

### 4. 安全邊界執行狀況

- ✅ 沒有輸入任何帳密、驗證碼、cookie、token
- ✅ 沒有嘗試繞過或完成任何 CAPTCHA／人機驗證
- ✅ 沒有按讚、留言、追蹤、轉發、發文、私訊、刪除、封鎖、改設定
- ✅ 私人收藏讀取：0筆（沒有登入路徑可測）
- ✅ 遇到登入牆（X的/explore、三站的收藏功能）一律停下，沒有重試登入

## 三、下一步建議（技術面，內容價值判斷交GPT）

1. **「熱門度篩選」要真的做，需要妹提供具體目標**：因為Bookmarks／收藏都需要登入，這條路目前只能讀「妳指定的公開帳號或貼文URL」，不能自動幫妳掃過整個個人化推薦流。如果妳想追蹤特定帳號的爆款貼文，把帳號或貼文URL給我，我可以照這份清單的格式批次讀取。
2. **是否要開放登入**：如果要讀妳自己的收藏/Bookmarks，技術上仍然只能請妳本人在這個Browser pane裡手動登入（我不會代勞輸入密碼），登入後的session能不能穩定保留待實測，這是下一階段如果妳同意才要做的事，目前不建議貿然嘗試。
3. **Threads的4個數字對應關係建議之後找一則自己貼文核對**：因為我沒有帳號可以登入比對，最準的驗證方式是妹自己貼文的已知讚/留言/轉發/分享數字，跟未登入讀到的4個數字比對順序，一次就能定案，不用我用其他公開帳號猜測。
